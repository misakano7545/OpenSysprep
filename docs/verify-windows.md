# Windows 虚拟机验证清单（净化补丁）

> 运行级验收。静态校验通过 ≠ 验收通过；必须在本清单全部通过后才算完成。

## 前置

- Windows 10/11 虚拟机 + 干净快照（每次验证前恢复快照）
- SC 封装工具：原版一份、净化版一份（分别封装）
- 可选：抓包工具（观察部署阶段是否有推广域名请求）

## 步骤

### A. 封装阶段

1. 用净化版工具执行一次完整封装（参数与原流程一致）
2. 封装产物（镜像/系统盘）检查：
   - [ ] IE 主页未被写入 `Start Page` 推广值
   - [ ] 无 `~ScLog` 或推广相关计划任务

### B. 部署后（目标机首启）

- [ ] IE 主页 = 原设置（未被改）
- [ ] Edge：主页/新标签页/默认搜索未被改（`Secure Preferences` 未被动）
- [ ] Chrome：同上
- [ ] 默认用户配置（新用户）未被改（`NTUSER.DAT` 默认主键）
- [ ] 搜索无 `tn=90013418_hao_pg`、无 `dh.sejai.com`
- [ ] 无 `newtabx.com` 出现（书签/主页/新标签页）
- [ ] 未出现 We2 标签页等推广扩展
- [ ] 原工具的其他功能（驱动、脚本、激活等）仍正常
- [ ] `%windir%\System32` 无异常新增 `Sc*` 文件（或至少无浏览器操作行为）

### C. 回归

- [ ] 与旧版封装产物逐项对比，除浏览器/推广相关外无差异
- [ ] 结论 + 截图归档到 issues 或 `docs/` 附录
